# Bible Outlines

Interactive learning experience for every book of the Bible — guided outlines, high-yield markers, type/antitype flashcards, and quizzes.

**Live site:** [https://apopovski.github.io/Bible-Outlines/](https://apopovski.github.io/Bible-Outlines/)

> The repo is currently private. Enable GitHub Pages (Settings → Pages → Deploy from branch `gh-pages` / root, or allow the Actions workflow on `main`) to publish the live site. Collaborators can also run `npm run dev` locally.

## Books

| Book | Status |
|------|--------|
| Genesis | Available |
| Exodus → Revelation | Coming as outlines are added |

Genesis follows the Seventh-day Adventist review outline (Patriarchs and Prophets), including 17 quiz questions with explanations.
